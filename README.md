# Minishell

A simple shell implementation in C.

## Branches

- **main**: The main branch of the repository containing the stable version of the code
- **copilot/add-main-branch**: Development branch for adding the main branch

## Building

To build the project:

```bash
make
```

## Requirements

- GCC compiler
- readline library

## Usage

```bash
./minishell
```

This will start the minishell prompt where you can execute commands.
